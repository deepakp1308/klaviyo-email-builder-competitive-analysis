# Klaviyo Email Builder — Competitive Analysis (Executive 2-Pager)

A two-page executive competitive brief on **Klaviyo's campaign Email Builder** — the WYSIWYG editor where ecommerce marketers design one-off email campaigns.

**Live site:** https://deepakp1308.github.io/klaviyo-email-builder-competitive-analysis/

## Scope

Deliberately narrow: **Email Builder / template editor surface only**.
Excludes Flows, SMS, segmentation, deliverability, Customer Hub, and Helpdesk.

## What's covered

- What the feature is and why it matters strategically
- Block library (13 native block types) and core editor capabilities
- In-editor AI: Email AI, Brand Voice Guidelines, Subject Line AI, Image Remix (Gemini), Marketing Agent, Personalized Campaigns AI
- Differentiators vs Mailchimp, Omnisend, Attentive
- Personas and jobs to be done with reference customers (Tatcha, Twinings, Marine Layer, LifeStraw, Alessi)
- Pricing tiers and which AI features are gated where
- Customer-reported strengths and gaps
- "So what" implications for our roadmap

## Sources synthesized

Klaviyo product pages, what's-new posts, help center, academy, developer reference, customer case studies, plus third-party reviews (G2, Gartner Peer Insights, Sender.net, Mailsoftly, Badsender, Polaris Growth, Uplers) and competitive comparisons (Zigpoll, Attentive blog).
